# Project Details

**Project Name:** PromptTweaker

**Subject Area:** Generative AI & Prompt Engineering

**One-line description:**
A browser-based tool that rewrites a user's prompt using three common prompt-engineering techniques (role/persona, few-shot example, chain-of-thought) and displays all four prompt versions side by side, so the effect of each technique is visible immediately.

**Problem it addresses:**
Prompt engineering concepts (role prompting, few-shot examples, chain-of-thought) are usually explained in text or slides. This project makes them tangible: the same base task is rewritten four ways, and the differences in structure and instruction are visible in one screen — no AI call or account required.

**Key features:**
- Single input box for a plain-language prompt
- Instant generation of 3 enhanced prompt variants
- Side-by-side comparison of all 4 prompt versions
- A short explanation under each card of why that technique helps
- No backend, no database, no API key — runs entirely in the browser

**Tech stack:** HTML, CSS, JavaScript

**How to run:** Open `index.html` in a browser, type a prompt, click "Compare prompts."
